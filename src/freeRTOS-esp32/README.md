BUTTON-LED

TaskButton (Core 0, Пріоритет 1): обробка кнопки

TaskLED (Core 1, Пріоритет 2): вмикає-вимикає світлодіод на заданий період

TaskDisplay (Core 1, Пріоритет 1): OLED

Передача даних через Queue (Черги):

intervalQueue : заштовхуємо час світіння діода від TaskButton до TaskLED

displayUpdateQueue : TaskButton передає щойно вибраний новий стан, TaskLED передає активний стан(потрібен час щоб обраний стан став активним)



DEADLOCK 

Стандартний дедлок, одна таска тримає те що хоче інша і хоче те, що тримає інша.
Додав вачдог, при блокуванні він не ресетається і тому за кілька секунд прилітає помилка.


LORA-LED-ASYNC

TaskLED (Core 1, Пріоритет 3): Світить кожні 100мс

TaskLoRaTX (Core 0, Пріоритет 1): Відправка по радіо
